DIGITAL SAFETY · 5 MIN READ

Use public Wi‑Fi more safely

Confirm the exact network name with staff before connecting. Avoid banking, payment cards, password changes and other sensitive tasks when using public Wi‑Fi.

Keep devices updated, turn off automatic connection to open networks and enable multi-factor authentication for important accounts. Never sign into essential accounts through an unexpected link or message.

Public Wi-Fi is useful for maps and basic messages. Use a trusted connection whenever you need to manage something important.
